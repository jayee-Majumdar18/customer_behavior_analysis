# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data to uncover valuable business insights. The analysis covers data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and dashboard creation to support data-driven decision-making.

The project follows a complete data analytics workflow using Python, MySQL, and Power BI, with findings documented in a report and presentation.

---

## Dataset

The dataset contains customer purchase transactions and includes information such as:

* Customer demographics
* Product categories
* Purchase amounts
* Subscription status
* Discounts and promotions
* Purchase frequency
* Customer ratings
* Shipping preferences

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python.
* Explored dataset structure and summary statistics.

### 2. Data Cleaning

* Handled missing values.
* Standardized column names.
* Performed data quality checks.
* Created additional features for analysis.

### 3. Exploratory Data Analysis (EDA)

* Analyzed customer demographics.
* Explored purchasing trends.
* Examined product category performance.
* Identified customer behavior patterns.

### 4. SQL Analysis

Business questions were answered using MySQL, including:

* Revenue analysis by customer segments.
* Subscription behavior analysis.
* Product performance evaluation.
* Customer segmentation.
* Purchase frequency analysis.
* Discount and promotion effectiveness.

### 5. Dashboard Development

An interactive Power BI dashboard was created to visualize:

* Revenue trends
* Customer segments
* Product performance
* Subscription insights
* Key business KPIs

### 6. Reporting & Presentation

* Documented findings in a detailed project report.
* Created a presentation summarizing insights and recommendations.
